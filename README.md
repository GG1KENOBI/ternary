# Тернарные языковые модели: обучение (TED) и быстрый запуск на процессоре

Веса модели — только −1, 0, +1 (≈2 бита на вес). Две цели:
1. **Своя тернарная модель для русского** — метод обучения TED (целочисленное положение веса + вероятностное округление, оптимизатор в int8/int16), комплект для обучения на 3×RTX 6000: `release/`.
2. **Быстрая работа на обычном процессоре** — переупаковка формата TQ2_0 и ядра для llama.cpp: `cpu/`.

| Где | Что |
|---|---|
| `ЦЕЛИ.md` | **начать отсюда:** где мы по обеим целям, команды для следующих шагов, какой скрипт дал какую модель |
| `REPORT_RU.md` | технический отчёт: метод, теория, все опыты и замеры |
