Тернарные модели на обычном процессоре

Одни и те же задачи для наших тернарных моделей и для моделей для сравнения. Ответы получены без видеокарты, жадным выбором слов (без случайности), поэтому их можно воспроизвести.

* Пиковая память процесса с контекстом на 16 тыс. токенов; у переупакованных моделей сюда входит и копия весов в новом порядке, и страницы исходного файла. Скорость чтения запроса — среднее по задачам пересказа.

Работает, когда страница открыта через локальный сервер: bash ternary/demo/start.sh, затем http://127.0.0.1:8090. Модель выбирается ниже; при смене она загружается за несколько секунд (в памяти держится одна).
