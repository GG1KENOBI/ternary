# Preflight Windows для HF-обучения GigaChat MoE

Короткая диагностика окружения. Ничего не устанавливает, не скачивает веса и не обучает
модель. Нужен маленький JSON, чтобы понять, можно ли переходить к реальному пилоту.

## Команда (PowerShell)

```powershell
cd release\windows_training
py -3 preflight.py --gpu 1 --out training-preflight.json
```

По умолчанию выбирается физическая GPU1. Выбор идёт строго по UUID из `nvidia-smi`:
до импорта torch выставляется `CUDA_VISIBLE_DEVICES=<UUID>`, поэтому внутри процесса
выбранная карта — локальная `cuda:0`. GPU0 и посторонние процессы не трогаются.
Если GPU1 нет или она занята compute-процессами, будет ошибка без молчаливого перехода
на другую карту. Отчёт сохраняется в любом случае.

## Что проверяется

- Python: версия, разрядность, реализация.
- ОС: system/release/version/machine.
- Свободная системная RAM (на Windows — `GlobalMemoryStatusEx` через `ctypes`).
- Место на диске, куда пишется отчёт.
- Версии `torch`, `transformers`, `accelerate`, `safetensors` через `importlib.metadata`;
  отсутствие пакета не является ошибкой установки.
- Таблица `nvidia-smi`: index, name, uuid, memory.total, memory.free, driver_version.
- Занятость выбранной GPU по compute-процессам.
- Если torch и CUDA доступны — крошечный BF16 forward/backward 128×128 с проверкой
  конечности loss и градиента, `synchronize` и освобождением тензоров.

`status=ok` и exit code 0 означают только успех BF16-теста. Это проверка окружения,
а не готовность полноценного пилота.

## Что прислать

Один файл `training-preflight.json`. В нём нет ключей, токенов, полного env, путей к
приватным файлам или SSH-данных. Достаточно прислать JSON целиком.

## Что НЕ запускается

- Установка библиотек, WSL и переустановка ОС.
- Сеть, загрузка checkpoint и любых весов.
- Загрузка FP8, обучение, проверка сходимости и качества после тернаризации.
- GGUF-экспорт и инференс.

Эти пункты в отчёте всегда помечены `not_tested`.

## Следующие решения

1. **FP8.** Официальный instruct-checkpoint — FP8 с блоками 128×128. Нужно решить,
   делать ли явное деквантование в BF16. Удалять `quantization_config` недостаточно:
   без `weight_scale_inv` веса будут неверными. BF16 base допустим только для
   механической диагностики, не как замена instruct-основы основного пилота.
2. **Чат-шаблон.** `prepare_data.py` сейчас формирует Qwen-разметку. Для GigaChat нужно
   использовать `tokenizer.apply_chat_template` с его шаблоном
   (`<|role_sep|>`, `<|message_sep|>`); иначе chat-данные токенизируются неверно.
3. **Версия.** Для пилота зафиксировать transformers 4.57.3 и проверить формат экспертов
   на реальной загрузке.
